# Simulador de l'aparell circulatori

Primera versió d'un simulador educatiu per a 5è de primària.

## Fitxers
- `index.html`: estructura de l'aplicació
- `style.css`: disseny
- `script.js`: animacions, interaccions i qüestionari

## Publicar amb GitHub Pages
1. Crea un repositori nou a GitHub.
2. Puja aquests tres fitxers.
3. Ves a **Settings → Pages**.
4. A **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona `main` i la carpeta `/ (root)`.
6. Desa i espera que GitHub generi l'enllaç.

No necessita servidor ni base de dades.
